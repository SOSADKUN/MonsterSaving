# Sprout Hamster companion

Prepared with the built-in imagegen tool in identity-preserving reference-edit mode, using only the user's supplied hamster reference sheet. Genuine transparent PNG; no background or character primitives. Original generated output is preserved separately.

App asset: `assets/images/monster/hamster_atlas.png` (1774 × 887 RGBA). Frame coordinates and optional orientation corrections are editable in `assets/images/monster/hamster_atlas.json`. Each frame shows one isolated character, never the entire sheet. Bounds were measured from alpha > 48 with three pixels of padding. Very low-alpha background RGB speckles are effectively transparent; original PNG pixels were not postprocessed.

Pose order: idle, happy, sad, walk1; walk2, eat, sleep, blink. The second walking pose faces left in the generated sheet and is mirrored by the frame painter to face right consistently; travel direction is applied separately. The two poses are a stylized walking loop, not a full skeletal animation.

First hatch: a 50/50 dinosaur/hamster choice is made once per onboarding instance and saved with ownership when the reveal artwork loads. The starter is free. The other companion costs 100 earned coins (`Ledger.companionPrices`); purchases and active selection persist in local saves/backups. Existing saves retain dinosaur ownership. Switching preserves financial records, achievements, levels, accessories and backgrounds.

No tests, analysis, builds or device installation were run for this enhancement, following the user's preference.
